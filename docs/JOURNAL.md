# Журнал порта Jetpac → Вектор-06Ц

## 25–26.10.2026 — от каркаса до играбельной версии

**Исходник и эталон.** Дизассемблер mrcook (SkoolKit, картридж) — подмодуль upstream/. tools/mkbin.sh: блоки
`i$` (неиспользуемый код) skool2bin выбрасывал со сдвигом — заменены на defs; `-s` — шрифт копией (оригинал
читает ПЗУ картриджа $3A00). Эталон ZX на JS: tools/zx48.js (Z80.js, ПЗУ 48K, INT 32 такта), zx_trace.js
пишет шаги = проходы главного цикла (FRAMES-очередь, порты, ld a,r, звуки, такты). 8 сценариев
(research/scenarios: случайный, бот tools/policies/bot.js, уровни, двое, джойстик, висение, рекорд).
Оригиналы владельца (кассета .tzx, снимок .sp) — другая сборка, побайтно с картриджем не сравнимы.

**JS-модель** (src/model): проход целиком, вывод в экран ZX (лазер читает экран!). 0 расхождений с ZX на
~70 тыс. проходов (tools/model_run.js).

**i8080** (src/vec, tools/build_vec.sh -> rom/jetpac.r0m, .c00): сверка tools/lock80.js с эталоном по
проходам — 0 расхождений на всех 8. Устройство и решения — docs/LOGIC_PLAN.md.

**Решения владельца по ходу:** 3 плоскости без клэша; JS-модель → i8080 с оптимизацией; графика на SP;
стирание только своих плоскостей ради скорости (логика расходится с ZX редко: 1 проход из 15000);
палитра «холодная» (вариант 4), Джетмен — голубой заставки (своя плоскость), зелёный → салатный, жёлтый →
золото заставки; заставка картриджа раскрашена в 16 цветов (tools/mksplash.py) и растянута на 256 строк
по областям (логотип и надписи как есть); пауза — ВК; бессмертие — F1+F3 в меню; мелодия BBC Micro-версии на
старте (docs/BBC_TUNE.md; в конце игры её нет).

**Звук:** ВИ53 канал 2 асинхронно (игра не ждёт), эффекты — шаги по тактам петель бипера ZX с поправкой на
спорную память, переключаются из диспетчера по секундомеру (канал 0) — точнее кадра. Мелодия — каналы 0..2,
управляющее слово только на новой ноте (иначе щелчки).

**Плавность (главные грабли дня):**
- Прерывание при DI на Векторе теряется (vector06js и Emu80 — ~30 % кадров, блиттер держит DI на плоскость).
  Кадр считает прерывание (синхронно с лучом), потерянный досчитывает frames_sync по секундомеру, порог —
  1,5 кадра из калибровки при загрузке (fs_calib). Чисто по секундомеру — нельзя: фаза уходит от луча,
  Джетмен двигался дважды за кадр.
- Вложенный проход (Джетмен + лазеры, по смене кадра) у нас 0,36 кадра против 0,18 на ZX — отнимает время у
  пришельцев. Пауза ограничителя (пустые слоты) уменьшена до 30 витков — ход пришельцев ближе к ZX
  (в основном раз в 2 кадра), но трёхкадровых интервалов всё ещё больше, чем на ZX.
- Ракета на взлёте/посадке: сдвиг на строку одним проходом (rk_move) — без мигания.
- Замеры в живом эмуляторе: build/smooth.js (интервалы Джетмена/метеора), tools/vecplay.js, vecshot.js.
  MCP Emu80 (tools/emu80_mcp.sh, порт 19787): при замере частоты учитывать время самих вызовов.
