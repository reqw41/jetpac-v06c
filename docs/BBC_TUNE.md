# Мелодия BBC Micro-версии (26.10.2026)

Источник: дискета пользователя `Disc007-JetPac.ssd` (в git не кладётся; распаковка — ref/bbc, локально).
BBC-версия: David Rhys Jones, 1983. Загрузчик `jet-ldr` (BASIC: инструкция) → `jetpac` (&5C00, звёзды
MODE 7) → `JET-PAC` (&2000, 14 848 Б): с &5900 переносит себя на &0700 (рабочий адрес = адрес в файле − &1900)
и стартует с &2F00. Дизассемблер — py65 (`build/dis6502.py <файл> <база> <от> <до>`).

## Звук в BBC-версии
Всего два вызова OSWORD 7 (SOUND):
- &146E — мелодия: подпрограмма &1450, 38 шагов по таблице &1420 (+&30 к высоте), каналы &11..&13 по кругу,
  огибающая 4, длительность 3 (150 мс), пауза OSBYTE &81 15 сс между нотами. Вызывается одним путём:
  меню ждёт клавишу (&1276, OSRDCH), ПРОБЕЛ → &1200 → (если звук включён, &24 = 0) *FX201,255 (клавиатура
  выкл.) → мелодия → *FX201,0 → игра. То есть **мелодия только на старте игры**; в конце игры её нет.
- &18A2 — шум взрыва (канал 0, громкость −15, 1 с) при гибели.

Огибающая 4 (из образа, &08F0): T=1, PI = 0, +1, −1 по 4 шага (вибрато 1/4 полутона), AA=126 (сразу громко),
AD=AS=−1, AR=−2 — звон с медленным спадом.

## На Векторе (src/vec/main.asm, tune_play / mus_tick)
Старт игры из меню → new_game → мелодия (игра ждёт, как на BBC). Три канала ВИ53 по кругу, нота звенит
11 кадров (~1,5 ноты), 150 мс = 8/7 кадров попеременно, вибрато: кадры 4..7 из 12 — делитель меньше на 1/64.
Строй выровнен по нотам. Превью оригинала (синтез по нотам и огибающей): ref/bbc/jetpac_bbc_tune.wav.
